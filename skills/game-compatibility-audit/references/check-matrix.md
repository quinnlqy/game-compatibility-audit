# 按目标选用的适配检查矩阵

只执行适用且与任务相关的项。以下尺寸、时长和触控目标是选样参考，不是统一平台规范；取项目支持范围的最小／常用／最大值及出问题的边界。

## 1. 窗口、安全区和图像布局

| 检查 | 关键条件 | 观察结果 |
| --- | --- | --- |
| 有效可用区域 | 窄竖屏、短横屏、平板、矮iframe／分屏；开着面板改变大小 | 根界面和裁切容器内完整可用，布局不只依赖屏宽 |
| 原生覆盖 | 状态栏、底部手势区、宿主返回／分享按钮；接口缺失、迟到、安全区变化但无resize | 不重叠、不重复累加安全区；坐标单位与比例一致 |
| 关键操作与信息 | 关闭／确认／取消、价格、数量、等待提示；最长真实文本、大余额、空／满列表 | 整体不被裁切或遮挡；手指实际能点；项目触控尺寸规则满足 |
| 短空间分配 | 内容图、展示台、价格、底栏共同占高 | 先保留操作／信息，图像合理缩放或内容滚动；只提高层级不能解决祖先裁切 |
| 装饰与文字分离 | 边框安全内圈、透明留白、九宫格源切线与显示边宽 | 圆角固定、文字可读、边框不压内容；不整体拉伸有形状语义的按钮 |
| 缩放与密度 | 常用DPR及分数DPR、小数坐标、125%／150%缩放 | 无采样漏缝、断线、点击坐标漂移；检查画面不只查边界矩形 |
| 字体与设置 | 系统字号／浏览器缩放、项目语言、辅助功能设置 | 不静默隐藏重要文字；有滚动路径可读完 |

H5可选样本：320×568、360×640、390×844、430×932；568×320、844×390；针对短窗口加844×300、360×280；平板768×1024／1024×768；桌面1280×720。它们是CSS可用区域，不对应唯一型号，超出支持范围标范围外而非必然缺陷。高DPR不直接等于高物理PPI。

## 2. PC模拟器、鼠标、触摸及游戏命中

| 检查 | 条件／动作 | 预期 |
| --- | --- | --- |
| 同包PC／手机对照 | 实际平台PC模拟器鼠标，手机手指，桌面自动化另记 | 打开、主要动作、关闭、再次打开均有效；不能只依赖touchstart |
| 点击区域 | 点击图、字、按钮边缘；检查透明装饰、遮罩和原生按钮占位 | 整块项目规定触控区域有效，不被装饰吞事件 |
| 长按与补发事件 | 按住、提前原生contextmenu、松手点击、延迟模拟鼠标事件 | 同一手势不误取消／重复触发；按住开菜单后的松手不点中危险操作 |
| 新输入与辅助激活 | 长按后新的轻点、真实鼠标左右键；已有键盘／辅助输入 | 不因旧手势保护吞新操作；detail=0等字段不能单独证明输入来源 |
| 拖动和确认 | 手指抖动、滑入操作栏、双指缩放、丢捕获、取消、失焦／后台 | 命中与拖动容错区分输入方式；UI上点确定不改场景预览位置 |
| 触摸平板 | 大视口、触摸笔、外接鼠标混用（项目支持时） | 大视口不被误当只能鼠标操作；布局、输入与性能判断分别处理 |
| 3D／Canvas命中 | 画布偏移／缩放、前后重叠、隐藏状态模型、多实例 | 坐标相对实际画布；按可见目标和前后距离选择；隐藏网格不抢点 |
| 冲突／摆放提示 | 家具重叠、大物遮挡、取消与确认 | 预览可辨认，正式提交恢复材质／层级，位置与扣费正确 |
| 列表交互 | 鼠标滚轮／拖动、手机滑动、分类／排序／列表首尾 | 不重复注册处理器、不串操作；原生滚动条不挤掉价格 |

事件注入属于构造边界测试。不要把注入顺序写成玩家手机实际日志，也不要通过全局点击冷却时间掩盖新输入不可用。

## 3. 资源和发布包（按引擎选用）

- 实际ZIP／安装包：入口层级、子路径、资源复制、文件大小写、编码／压缩格式、静态和动态引用。按每个目标校验，不能重命名其他平台包代替构建。
- H5路径：CSS变量与伪元素的解析基准，PNG转WebP后的独立脚本，宿主不透明地址映射，查询参数及内容缓存指纹。用大小写敏感环境复测，避免Windows掩盖问题。
- 图片就绪：load／error、有效尺寸、缓存命中；decode等接口缺失／拒绝／同步抛错／挂起。不把某个接口异常等同文件不存在。
- 等待、取消、切分类、迟到结果、关闭重开：旧异步结果不覆盖新选择、不重新打开已取消面板。
- 必要图与可选装饰分开：装饰失败可名称／文字占位，保留可用操作；关键资源真失败明确错误与重试，不能显示假成功。
- 生命周期：冷启动、停留后首次开面板、资源服务或虚拟目录失效、后台返回。平台不允许请求／缓存方式时使用合规实现；是否将图片常驻页面需权衡目标内存与生命周期，不能不经测量将全部资源常驻作为通用方案。
- 跨平台隔离：只包含该目标SDK、活动、配置、文案及专属素材，隐藏按钮不等于移除平台内容。

## 4. 旧环境、渲染、音频和生命周期

- 依据最低支持范围测试实际用到的DOM／语言API、尺寸观察器、可选加密、空闲回调；分别检查缺失、抛错与不返回。兼容补丁早于依赖模块初始化。
- 构建语法检查覆盖主包和独立外置脚本；CSS支持与运行API另测。检查dvh／动态视口、定位、选择器、间距及原生滚动条回退。
- WebGL1／2及项目渲染后端：贴图解码／上传、色彩空间、蒙皮动画、后处理、GPU上下文丢失恢复。改变UA不代表换了WebKit或GPU。
- 黑图时区分几何、灯光、贴图与后处理；查当前完整游戏路径，旧专项测试的原始加载器失败不自动代表当前补丁路径失败。
- 冷启动计时含脚本解析、平台核对、实际需要资源及首帧；记录网络、CPU、缓存、设备和包指纹。桌面降速结果不能宣称为真实手机秒数。
- 后台冻结／恢复、大帧间隔、锁屏、方向变化：视觉时间与应结算的离线玩法时间分开；不能靠重置全部进度修花屏。
- 音频：首次交互启用、静音记忆、后台暂停／返回、解码失败恢复；区分能力禁用、自动播放限制和音量。
- 平台／系统弹窗：调色、文件、相册、权限等实际原生界面的打开／取消／返回／确认；脚本触发change事件不能替代真实系统界面验收。

## 5. 保存、消费和恢复（有此能力时）

- 启动分阶段判断：脚本／资源／WebGL／存档核对／恢复前备份。保留数据而停在loading可能是保护结果；同时报告玩家仍无法进入，不能当作体验已恢复。
- 购买／领取／放置实际执行一次；连点、等待时关闭、失败、未知回执、重试、中断重开后不重复扣费或发放。
- 原生调用返回成功不一定持久化成功；按项目协议回读／核对，失败或不确定时不显示已保存。
- 主档、备用、照片／日记共享配额；小额写探测成功不代表大备份可写。保留原始记录和可恢复副本，不让排查清空玩家存档。
- 账号／设备隔离、只读云、离线、本机不可写、文件导入后旧场景继续操作等按目标能力覆盖。无云目标不增加云功能；缺少SDK事务不声称完全原子。

## 6. 收敛测试量

选择能解释风险的最小交叉组合：常规状态＋最拥挤状态＋关键能力缺失＋原反馈条件。先以代表尺寸复现，再扩受影响边界；不要将所有尺寸×所有状态×所有设备无条件全排列。

真实设备优先原反馈设备、不同内核／宿主、旧支持边界、大屏触控及中低端性能设备。无法取得时列出缺口，而不编造真机验证。

## 7. 从实际故障补入的高风险组合

以下是跨项目可复用的机制，细节见[编号回归](regressions.json)，不要求游戏存在原案例的玩法。

| 风险组合 | 重点观察 | 编号 |
| --- | --- | --- |
| 短窗口＋宿主上下栏＋固定工具面板 | 按实际内容容器分配高度；画布、操作与返回都可达；菜单只留一次侧栏 | V01–V05、V10 |
| 平板直接冷启动＋字体／容器晚布局 | 不依赖先以手机打开再旋转来“修好”；背景、前景与命中一致 | V07 |
| 新缩放系统＋旧像素适配器 | 不重复放大；DPR用于采样，不能直接把CSS界面除小 | V08 |
| 新布局＋欣赏／相册／弹窗状态 | 制作工具不在查看页重新出现；离开后恢复旧结构与样式 | V09 |
| 真实工具预览＋DOM材料区＋Canvas | 拿起、跨区、捕获后返回UI均可见；影像不拦点击且退出无残留 | I02–I03 |
| 触摸释放中断＋下一次单指 | 无旧触点残留、不误触双指；取消后不补画或沿用旧动作 | I01、I03 |
| 花嘴／颜料／分类列表＋按下即拿起 | 原生滚动与拖动分开；纵向滑动不被pan-x或全局preventDefault阻止 | I04 |
| 长按开菜单＋松手补发click＋新的轻点 | 同手势不误提交，真正新动作仍可用；不采用全局点击冷却掩盖问题 | I05 |
| 老WebView＋现代API／选择器 | 独立入口也要前置兼容；测试后续路径与CSS失效，不只转译脚本 | J01–J06 |
| 尺寸监听＋画布固有尺寸 | 通知不误报致命错误，布局也不逐帧增长；不关闭全部诊断 | R01–R02 |
| 局部发黑＋自动降级 | 健康对照与读回有效；不确定不当成确认，手动选择优先 | G01–G03 |
| 编辑弹窗＋高清导出＋后台3D | 日常编辑不每次编码大图／重编材质；隐藏绘制暂停，退出释放 | G04–G05 |
| 购买／结算＋主写超时／备份挂起 | 超时不代表写取消；防迟到覆盖、重复扣发与无限保存中 | S04 |
| 本地／云恢复＋账号切换 | 不跨账号／平台合并；旧恢复数据不覆盖新进度，永久权益按项目协议保护 | S06 |

为新游戏选样时优先“最拥挤状态＋原反馈条件＋健康对照”，再扩受影响边界。上述频次为来源项目的定性经验，不是设备故障率。
